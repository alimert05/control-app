# Screenshots

No screenshots have been added yet. When you take them, save them in this folder (PNG, landscape)
and reference them from the main
[README](../../README.md) in its **Screenshots** section.

Suggested set:

| File | Shows |
|---|---|
| `dashboard.png` | the Default profile's Dashboard page, connected |
| `media.png` | the Media page with a track playing |
| `edit-mode.png` | Edit Mode with a widget selected |
| `profiles.png` | the profile switcher popup or the Manage Profiles dialog |
| `tray-menu.png` | the Windows tray menu showing connection and advertising status |

Check that a screenshot shows no personal information (PC name, track names you would rather not
publish) before committing it.
